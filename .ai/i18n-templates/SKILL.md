# i18n и шаблоны (crm-tg-app)

## Когда применять

Активировать этот скилл каждый раз, когда меняются:

- значения в шаблонизаторах, например `{{ что-то }}`;
- текст в Vue-шаблонах (страницы, компоненты в `crm-tg-app/app`);
- подписи в списках, кнопках, формах, навигации.

## Локали

- Папка локалей: **`crm-tg-app/i18n/locales/`** (от корня репозитория).
- Файлы: **`en.json`**, **`ru.json`** — структура ключей в обоих должна совпадать.

## Обязательные шаги

1. **Текст в шаблоне**
   - Любой пользовательский текст выводить через `$t('key')`, а не хардкодом.
   - Пример: `{{ $t('nav.getStarted') }}` вместо `{{ 'Как начать' }}`.

2. **Ключи в локалях**
   - Каждый ключ, используемый в `$t('...')`, должен быть в **обоих** файлах: `en.json` и `ru.json`.
   - Иерархия ключей должна совпадать (одинаковые вложенные объекты, например `getStarted.title`, `news.description`).

3. **После изменений**
   - Добавить или обновить ключ в **en.json** (значение на английском).
   - Добавить или обновить тот же ключ в **ru.json** (значение на русском).
   - В шаблоне использовать только ключ: `{{ $t('section.key') }}`, без дублирования текста в кавычках как fallback (или оставить осознанный fallback по необходимости).

## Проверка

- Поиск по проекту: все вхождения `$t('...')` в `crm-tg-app/app` — извлечь ключи.
- Для каждого ключа: наличие в `crm-tg-app/i18n/locales/en.json` и `crm-tg-app/i18n/locales/ru.json`.
- Если ключ добавлен только в один файл — добавить во второй с тем же путём (на нужном языке).

## Пример

В шаблоне добавлено: `{{ $t('settings.theme') }}`.

1. В **en.json** добавить (при отсутствии): `"settings": { "theme": "Theme" }` или отдельный ключ `"settings.theme": "Theme"` в зависимости от текущей структуры.
2. В **ru.json** добавить то же место в структуре: `"theme": "Тема"` внутри `settings`.
3. В шаблоне оставить только `{{ $t('settings.theme') }}`.
